# Security

Do not post credentials or private photos in issues. Use GitHub's private vulnerability reporting when available; otherwise describe the issue without exploitable details or sensitive data and request a private reporting channel.

Keep generated data and secrets outside Git. Configure a bearer key for network access, use HTTPS, and apply access controls appropriate to your application. The engine has no user-account system. Host applications own authentication, ownership checks, request limits and retention policies.

Reference downloads use trusted source hosts. Model downloads are pinned and verified. Portable bundles enforce a member allowlist. Integrity checks do not replace choosing a trustworthy artifact source.
